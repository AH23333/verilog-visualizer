## 编译模式 / Compile Mode

### 打开与编译文件 Open & compile
- **文件 → 导入 Verilog 文件…**（多选）或示例库载入；编辑器 **F5** 编译。
- 综合走 Yosys WASM，默认流稳定、`EXPERIMENTAL_FLOW` 实验流（yosys `synth` 官方流程）可在设置中说明的语境下试。
- **接口预检**先于渲染：端口被错误宽度表达式驱动、net 不存在等逐条进 PROBLEMS；**无名多位冲突 → 拒绝编译并解释**，**具名冲突 → 照常出图 + 冲突逐条标问题**（网表类文件的分级策略）。

### 读图与交互 Read & interact
| 操作 | 效果 |
|------|------|
| 点输入开关/时钟 | 翻转电平，信号即时传播 |
| 悬停连线 | 浮层显示网名 = 数值 |
| 点击连线 | **高亮该连线本身**（紫描边）；点器件亮器件 |
| 双击子模块 / 🔍 | 内部电路弹窗（同管线同坐标，可逐层钻取） |
| 代码 ↔ 电路 | 光标行 → 对应单元高亮；选单元 → 跳源码行 |
| 视图菜单 | 适应窗口 / 放大 / 缩小 / 主题切换 |

### 问题面板 Problems panel
PROBLEMS 逐条列出错误/警告（含真实行号），点击跳源码；「代码干净」时显示通过态。

## 沙盒模式 / Sandbox Mode

### 文件系统 File system
- 左侧 ActivityBar **沙盒** 进入；文件树支持 **新建电路/新建文件夹/重命名/删除/拖拽移动/右键导入导出**。
- 两类文件：普通电路 `.djs` 与 **部件文件**（`role:'part'`，同样是可编辑 `.djs`，出现在部件面板）。
- 删除部件文件会提示对既有实例的影响；实例存档为引用式（不内联定义），单一真源。

### 画布编辑 Canvas editing
| 操作 | 快捷键/入口 |
|------|------------|
| 放置器件 | 部件库分组点选；或右键 → 放置部件（两级导航） |
| 连线 | 端口拖出；位宽不匹配自动插零扩展/总线切片并提示 |
| 多选/框选 | Shift/点选累加；空白拖拽框选 |
| 复制/粘贴 | Ctrl+C/V（跨文件；匿名子电路自动 ensure-def） |
| 旋转 | Ctrl+R（多选绕选区中心，90° 步进） |
| 镜像 | 右键 → 水平/垂直（模型级镜像，随存档往返；文字保持正向） |
| 对齐/分布 | 多选右键 |
| 撤销/重做 | Ctrl+Z / Ctrl+Shift+Z（80 步全量快照） |
| 保存 | Ctrl+S + 切档自动落盘 + 可选自动保存（设置面板，防抖） |

### 逐器件配置 Per-device reconfiguration
右键器件 → 参数项（改动走**重建式**：保 id/位置/连线，因 digitaljs 部分参数仅构造期生效）：
- **存储器 Memory**：端口配置…（读写口、时钟、使能、复位值、初始化数据）
- **状态机 FSM**：转移表…（状态、迁移、初态）
- **寄存器 Dff**：端口与极性…（时钟/使能/异步复位/同步复位/置位/清零，逐脚高/低有效，无 D 脚锁存模式）
- **算术/比较/移位**：位宽、逐操作数有符号（双有符号才生效，Verilog 同则）、移位补 x
- **门族**：输入引脚数 2–16；**总线**：位宽方案/分组；**IO**：名称/位宽/初值/进制
- **总线切片 BusSlice**：切片配置 `起始位:结束位`（**含两端**：`0:3` 取 4 位、`1:1` 取 1 位，兼容 `3:0` 降幂）＋ 总线总位宽

## 部件与绑定 / Parts & Bindings

- **保存为部件**：画布（≥1 输入 + ≥1 输出）→ 命名 → 生成部件文件；嵌套子部件递归入库。
- **绑定解析**：实例按 `celltype` 名绑定部件文件；优先级 = 当前文件显式绑定 > 同文件夹部件 > 根部件 > 全库兜底。
- **部件绑定弹窗**（文件右键「部件绑定…」）：原生弹窗会话列出本文件全部实例（含深层部件的内部实例）→ 逐项标注当前生效解析（已录/自动同名/未绑定）→ 选实例再选部件即写进该目录的 `.verilogviz.json`；弹窗内「打开绑定配置」行可直达 JSON 手改。
- **循环依赖保护**：把部件放进自身或其闭包回指的部件文件 → 放置当场拒绝并展示环路径；存量环档案可正常打开，展开图把回边渲染为 ⟲ 空壳，顶部常驻警告条点名环。
- 「复制到沙盒」把编译电路的子模块一并递归转为文件夹收纳的部件文件并自动绑定。

## 表达式生成 / Expression Generator

工具栏 **表达式生成**：多行布尔式 → 电路。
- 语法：`out = a & b | c`、`~ !` 取反、`^` 异或、`& |` 与或；多位：`a[3:0]` 切片（含两端）、`{a, b[1:0]}` 拼接（左侧落高位）、常量 `4'b1010`；
- 多语句级联：后续语句可引用前面语句的输出；相同子表达式 CSE 共享；
- 一键 **直接存为部件** 或放置到当前画布。

## 注释便签 / Sticky Notes

- 双击画布空白 → 便签出现且**已在输入态**；`Esc` 提交（新建空便签自动丢弃）；双击已有便签二次编辑。
- 自动换行（SVG 排版量宽，提交后盒子贴字）；拖 **边** 改比例、拖 **角** 等比缩放（文字随缩放）。
- 支持旋转/镜像（与部件同通道）；**编辑时永远正向文字**，提交后保持原变换。
- 随存档往返、参与复制粘贴/撤销重做；部件展开图内按**同一坐标系原位叠加**（相对位置零误差；自动重布局时暂隐以拒绝对不上位）。

## 波形调试 / Waveform Debug

工具栏 **波形**：通道列表（可勾选/滚动历史 600 tick）、跟随仿真速度；编译与沙盒模式同款面板。

## 导出与文件格式 / Export & File Formats

| 出口 | 格式 | 说明 |
|------|------|------|
| 导出 SVG | `.svg` | 深度重绘（计算样式内联，无 foreignObject，任何查看器可开） |
| 导出电路 JSON | `.json` | 编译格式（devices/connectors/subcircuits） |
| 导出综合网表 | `.v` | 结构化 Verilog（未覆盖器件以注释占位） |
| 导出 `.djs` | `.djs` | 沙盒存档；**自动附带引用闭包内的部件文件**（共享库可直接导入他人工程） |
| 导入 | `.v` / `.djs` | `.djs` 导入自动注册随行的部件定义 |

## 快捷键 / Shortcuts

应用内 **帮助 → 快捷键**（或 `Ctrl+/`）查看全部注册项；编辑器内 `Ctrl+F` 查找替换、画布上 `Ctrl+F` 部件搜索、`Ctrl+Shift+P` 命令面板、`F5` 编译、`Ctrl+S` 保存。

## 设置 / Settings

左栏 **设置**：主题（深/浅）、字号（全局 rem 联动，含编辑器）、网格与吸附、走线样式（**全局**：metro/正交/曲线，两模式即时生效）、沙盒自动保存（开关+间隔）、默认视图、仿真速度。
